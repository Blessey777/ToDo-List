# To-Do List App

## About the Project
A simple To-Do List application built using HTML, CSS, and JavaScript to help organise daily tasks.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Add and manage tasks
- Simple and user-friendly interface

## How to Run
1. Download the project files.
2. Open `index.html` in your web browser.
3. Use the application to manage your tasks.
